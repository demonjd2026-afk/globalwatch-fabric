01 · The problem

Air quality data is published, but not usable

Dozens of monitoring networks expose readings through incompatible APIs, at different cadences, in different units, with no shared classification. Nobody can answer "which stations breached the WHO guideline, and is it getting worse?" from one place.

Unify

Many countries into one conformed star schema, with a single WHO-based classification applied identically in the batch and streaming layers.

React

Detect a hazardous reading in seconds rather than on tomorrow's batch run, and act on it without a human in the loop.

Open up

Serve a BI analyst, an ad-hoc SQL user, and someone who only wants to ask a question in plain English — from the same tables.

Design constraint that shaped everything: the OpenAQ free tier allows 60 requests per minute. Reaching 70 country codes inside that budget drove a per-sensor /latest fetch and semaphore-bounded concurrency instead of serial polling.

The patterns behind the pipeline

PatternWhat it doesWhy it was chosen here
SCD Type 2 via Delta MERGEExpires the changed row, inserts a new version, one atomic operationStations get renamed and reassigned; a reading must stay attributable to the configuration that produced it
MD5 change hashOne hash comparison replaces column-by-column diffingKeeps change detection O(1) in table width — adding a column costs nothing
CRC32 surrogate keysDeterministic keys from the natural keyRe-running a load is idempotent; no distributed counter or coordination shuffle

05 · Reliability engineering

Four defects the dashboard surfaced

A duplicated row in the UI turned out to be four separate upstream faults. Each was traced to its layer and fixed there rather than patched at the display.

1
The watermark table was never read
last_watermark was referenced only inside a try/except NameError that caught its own absence and defaulted to the year 2000 — so the incremental filter passed everything, every run, and dead stations reporting values from 2016 reached Gold. Now bound from the control table, and it raises rather than defaults.
2
A clock-based watermark would have loaded nothing
The watermark advanced to current_timestamp(), but readings always trail run time — so fixing only the binding would have flipped the pipeline from loading everything to loading nothing. It now advances to max(reading_ts) of the batch actually loaded.
3
Append made re-runs non-idempotent
Bronze used mode("append"), re-landing rows on every execution. Replaced with a MERGE on (location_id, parameter, reading_ts) — the same grain Silver deduplicates by — with source-to-target schema alignment so dimension drift cannot abort the load.
4
SCD2 was fanning out the fact table
The dimension source used .distinct() over six columns, which is not one row per station — coordinate precision drifts between API calls, so each variant hashed differently and was inserted as its own current row. Five stations carried two active versions each, silently multiplying fact rows on the join. Now one row per station by recency, with a guard that fails the run before a fanned-out fact table is written.
